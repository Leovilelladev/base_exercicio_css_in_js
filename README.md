# EBAC Jobs

Projeto de uma página de vagas para tecnologia, design e artes visuais desenvolvido durante o exercício de CSS-in-JS da EBAC.

## Tecnologias

- React
- TypeScript
- Styled Components

## Como executar

Instale as dependências:

```bash
npm install
```

Inicie o projeto em modo de desenvolvimento:

```bash
npm start
```

A aplicação ficará disponível em http://localhost:3000.
